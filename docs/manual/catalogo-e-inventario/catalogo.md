# Catálogo

## Para qué sirve
Registrar productos y sus variantes, con nombres, identificadores y la posibilidad de aceptar pedidos sin existencias. Las cantidades disponibles se administran en Inventario.

## Antes de empezar
Entra a la sede autorizada. Necesitas permisos de consulta para ver productos y permisos de creación o edición para cambiarlos. Si aparece «No tienes permiso para consultar el catálogo en esta sede.», solicita acceso a quien administra los roles.

## Cómo se usa (paso a paso)
1. Abre «Catálogo» y pulsa «Nuevo producto» si tienes permiso.
2. Introduce «Nombre», «Slug» y «Descripción»; revisa la opción «Disponibilidad».
3. Pulsa «Crear producto». Para modificar uno existente, usa su edición y «Guardar cambios».
4. Abre el producto y registra una variante con «SKU» y «Nombre de variante»; guarda con «Crear variante».
5. Para importar archivos, utiliza «Generar vista previa», revisa cuántas filas tienen error y solo después pulsa «Confirmar importación». Esta acción confirma una importación real, no solo una vista previa.

## Avisos y mensajes
Si una consulta falla, utiliza «Reintentar». El estado de disponibilidad puede mostrar «Permitido» o «Desactivado». La vista previa informa de filas nuevas, existentes y erróneas.

## Limitaciones
Las existencias no se corrigen aquí. La interfaz muestra solamente las operaciones autorizadas para la sede y los permisos activos. Verifica productos y variantes antes de realizar importaciones.
