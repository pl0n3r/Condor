# Activos empresariales — solo pruebas

**Esta pantalla es de laboratorio y no está activada como módulo operativo en producción.** Utiliza referencias sintéticas; no tiene validez jurídica ni permite gestionar bienes reales.

## Para qué sirve
Ensayar la consulta y el registro ficticio de activos empresariales y de sus cambios de estado.

## Antes de empezar
Solo está disponible en un entorno de desarrollo autorizado. Necesitas permisos de consulta y, para ciertas acciones, permisos adicionales. Nunca introduzcas inventarios reales, datos personales o documentos legales.

## Cómo se usa (paso a paso)
1. En el entorno de pruebas, abre «Activos empresariales».
2. Para crear un ejemplo, pulsa «Alta ficticia» y rellena «Referencia de activo de prueba».
3. Confirma con «Inventariar activo ficticio» o abandona con «Cancelar».
4. Selecciona una fila para abrir «Detalle y acciones explícitas».
5. Si el ensayo lo requiere, escoge una «Acción ficticia»: «Asignar responsable», «Solicitar mantenimiento» o «Solicitar baja (no aprobar)».
6. Completa «Responsable sintético» o «Evidencia sintética» cuando corresponda, y pulsa «Registrar transición ficticia explícita».

## Avisos y mensajes
La pantalla puede mostrar «Sin activos ficticios.» o «Error de red o API sintética no habilitada.». Ante un fallo de carga, usa «Reintentar».

## Limitaciones
El registro no aprueba una baja, un responsable ni ninguna acción real. Las transiciones permanecen sujetas a revisión humana; no prueban cumplimiento contable ni legal.
