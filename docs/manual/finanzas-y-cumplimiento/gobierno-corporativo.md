# Manual de Gobierno corporativo

**Estado: simulación con datos inventados, solo disponible en el entorno de desarrollo.** No registra actas oficiales, poderes, juntas ni decisiones jurídicas reales.

## Para qué sirve

Permite practicar solicitudes de actuaciones de ejemplo, consultar sus estados y simular una revisión manual. Los datos se muestran dentro de la empresa y sede de prueba seleccionadas.

## Antes de empezar

- Abra el administrador de una empresa de prueba y elija «Gobierno corporativo (pruebas)» en «Finanzas y cumplimiento».
- Necesita permiso para consultar; la creación y la revisión requieren permisos adicionales.
- Prepare referencias imaginarias de actuaciones, órganos y representantes. No introduzca nombres verdaderos, números de identidad ni datos de sociedades reales.

## Cómo se usa (paso a paso)

1. Abra «Gobierno corporativo · simulación M15» y consulte «Actuaciones ficticias».
2. Use «Buscar actuación ficticia», «Filtrar por órgano» y «Filtrar por estado» para encontrar registros del ejercicio.
3. Con permiso para crear, pulse «Crear actuación de prueba». Complete «Referencia ficticia», «Órgano ficticio» y «Representante ficticio»; después elija «Clase».
4. Pulse «Registrar solicitud ficticia». Si la operación se confirma, encontrará el elemento en la lista de pruebas.
5. Seleccione una actuación y abra «Detalle y revisión manual». Cuando la opción esté habilitada, pulse «Solicitar revisión ficticia» o «Iniciar revisión ficticia» según su estado.
6. Consulte «Bitácora de demostración (no oficial)» para revisar movimientos del ejercicio; no es un libro de actas.

## Avisos y mensajes

- «Sin registros ficticios para estos filtros.» indica que la búsqueda no encontró coincidencias.
- «Registro ficticio confirmado por el servidor. Sin valor jurídico.» indica que se guardó una muestra, no un acto oficial.
- «Acceso denegado por el servidor para esta sede.» señala una restricción de acceso.
- «No se pudo cambiar el estado.» indica que debe comprobar los permisos y volver a consultar el elemento.

## Limitaciones

Las referencias auxiliares solo sirven para validar el formulario; no representan poderes ni autoridades reales. Ningún acta, facultad o decisión queda aprobada ni cerrada automáticamente. Las demostraciones no sustituyen procesos societarios ni asesoría legal.
