# Manual de SG-SST

**Estado: pruebas con datos inventados, solo en el entorno de desarrollo.** No certifica el Sistema de Gestión de Seguridad y Salud en el Trabajo ni permite registrar personas o incidentes reales.

## Para qué sirve

Permite ensayar el registro y la revisión de ejemplos de seguridad y salud en el trabajo, separados por sede. También conserva una simulación local anterior para prácticas sin conexión con los registros de prueba del servidor.

## Antes de empezar

- Ingrese al administrador de una empresa y sede de prueba; seleccione «SG-SST (pruebas)» en «Finanzas y cumplimiento».
- Compruebe sus permisos de consulta. Para crear o cambiar estados necesita permisos adicionales.
- Utilice nombres y referencias totalmente inventados: nunca datos de empleados, diagnósticos médicos ni accidentes auténticos.

## Cómo se usa (paso a paso)

1. Entre a «SG-SST · integración de prueba M03». Consulte «Registros SG-SST ficticios» y la lista de «Diez submódulos ficticios».
2. Con permiso para crear y la lista cargada, pulse «Crear registro ficticio». Elija «Submódulo» y complete «Referencia del registro ficticio» y «Referencia de fuente ficticia» con valores de prueba.
3. Confirme con «Crear registro ficticio». El registro aparece en el listado de la sede seleccionada cuando la operación termina correctamente.
4. Seleccione una fila para abrir su detalle. Si tiene permiso para modificar estados, elija «En revisión» o «Requiere revisión». Se registra una revisión ficticia, nunca una aprobación.
5. La simulación local anterior permite practicar con «Nuevo registro ficticio», consultar «Registros de demostración» y usar «Filtrar estado». Sus registros locales se descartan al recargar o cambiar de empresa.

## Avisos y mensajes

- «Sin registros SG-SST ficticios.» indica que no hay elementos de prueba.
- «Acceso denegado por el servidor.» indica que no se puede consultar la sede con la autorización actual.
- «No se pudo crear el registro ficticio.» significa que la creación no se confirmó.
- «Revisión ficticia registrada; no existe aprobación ni cierre automático.» confirma exclusivamente un cambio de prueba.

## Limitaciones

Los diez submódulos son demostraciones, no procesos certificados ni expedientes laborales. Ningún estado se aprueba o se cierra automáticamente. Las acciones locales no sustituyen una auditoría, y los registros del servidor de pruebas no constituyen cumplimiento legal.
