# Manual de Procesos y tareas

**Estado: función de laboratorio.** Presenta procesos y tareas ficticios; no está habilitada como operación real de producción.

## Para qué sirve

Permite consultar ejemplos de procesos y ensayar el cambio de estado de una tarea, sin guardar información ni enviar trabajo a nadie.

## Antes de empezar

- Entre en un entorno de pruebas donde esté disponible «Procesos y tareas».
- Seleccione la sede correcta. Para consultar necesita permiso; para simular cambios, una autorización adicional.
- No utilice estos ejemplos como comprobantes de labores ejecutadas.

## Cómo se usa (paso a paso)

1. Abra «Procesos y tareas» y revise «Tareas de la sede». La lista distingue tareas, procesos y procedimientos.
2. Use «Buscar proceso, procedimiento o tarea» para encontrar un ejemplo. Si no aparecen resultados, pruebe otra búsqueda.
3. Seleccione una tarea en la lista o pulse «Simular tarea».
4. En «Simular estado de tarea», revise «Tarea ficticia» y elija el «Estado de prueba»: «Pendiente» o «Completada (simulada)».
5. Pulse «Simular sin guardar» y lea el aviso de confirmación. El estado de una tarea real no cambia.

## Avisos y mensajes

- «Estado ficticio validado. No se guardó ni ejecutó ninguna tarea.» confirma el ensayo.
- «Sin permiso para ver procesos.» o «Sin permiso para simular tareas.» señala una restricción de acceso.
- «No fue posible consultar procesos sintéticos.» permite usar «Reintentar»; «No fue posible simular la tarea.» indica que el ensayo falló.

## Limitaciones

Los datos son ficticios y la simulación **no guarda registros ni despacha tareas**. Tampoco certifica la ejecución de procesos de una empresa. La opción de simulación puede no mostrarse si no hay tareas o faltan permisos.
